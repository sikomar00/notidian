Notidian 설정

준비 상황

    토큰을 넣기 전에 예시 데이터로 그래프를 먼저 써 볼 수 있어요(저장되지 않아요).

    1. 토큰 준비

    3단계로 준비해요.

    1. Notion에서 내부 연결을 만들고 권한은 콘텐츠 읽기만 켜요. (공식 안내)
    2. 읽을 상위 페이지를 열고 오른쪽 위 ⋯ → 연결에서 방금 만든 연결을 추가해요. 하위 페이지도 함께 읽혀요.
    3. 연결의 토큰을 복사해서 아래에 붙여 넣어요.

    PAT는 읽기 전용으로 만들 수 없어요. 토큰이 새면 Notion 내용을 바꾸거나 지울 수 있어요. 가능하면 내부 연결 토큰을 쓰세요.

    켜면 토큰을 디스크에 남기지 않고 메모리에만 둬요. 더 안전하지만, 브라우저를 다시 켜거나 확장이 새로고침·업데이트될 때마다 토큰을 다시 넣어야 하고, 그동안은 자동으로 다시 만들지 않아요.

    토큰은 이 브라우저에만 저장돼요. 암호화되지 않아서 같은 Windows 계정의 다른 프로그램이 읽을 수 있어요.

    2. 연결 지도 만들기

    먼저 위에서 토큰을 저장해 주세요.

    바뀐 페이지만 다시 읽어서, 바뀐 게 없으면 금방 끝나요. 브라우저가 켜져 있을 때만 돌아요. 직접 "멈추기"를 눌렀으면 건너뛰고, 자동으로 만들다 Notion이 잠시 막거나 오류가 나면 다음 주기에 이어서 해요.

    처음에는 몇 분 걸려요. 중간에 끊겨도 이어서 읽어요. Notion 검색이 수십 초 늦게 반영될 수 있어서, 방금 고친 내용은 잠시 뒤에 보일 수 있어요.

    3. 읽지 못한 페이지

      4. 데이터는 어디에 있나요

      • 모든 내용은 이 브라우저 안에만 저장돼요: Notion 토큰, 페이지마다 제목·주소·수정 시각·상위 페이지·소속 DB·읽기 상태, 페이지 사이의 연결(어느 페이지가 어느 페이지를 가리키는지), DB 이름, 언급 정리에서 뺀 제목, 색 그룹 조건, 그리고 본문 글자("연결 안 된 언급"을 찾는 데만 써요. 코드 블록·속성 값은 빼요). "저장된 데이터 지우기"를 누르면 모두 지워져요.
      • 이 확장이 접속하는 곳은 Notion 두 곳뿐이에요. api.notion.com에는 읽기 요청만 보내요(페이지·본문 읽기와 검색). app.notion.com에서는 페이지를 열고, 지금 보는 페이지 주소로 그래프에서 그 페이지를 찾아요. Notion 페이지 안에서는 가운데 창을 띄우는 작은 스크립트만 돌고, 페이지 내용은 읽지 않아요. 다른 서버로 보내거나 사용 통계를 모으지 않아요.
      • 토큰은 "토큰 지우기"로, 연결 지도(제목·연결·DB 이름 등)는 "저장된 데이터 지우기"로 따로 지울 수 있어요. "브라우저를 닫으면 토큰 지우기"를 켜면 토큰은 디스크에 남지 않아요. 확장을 삭제하면 저장된 내용이 모두 지워져요.
