# QA 가이드 (구현된 범위까지 채움)

기준은 [PRD](./03-prd.md)의 F·NF이고, 확인 주체는 PRD 확인 열을 따른다. 결과는 **기대값·실제값·Pass/Fail·날짜**로 적는다. 실패는 숨기지 않고 [Intent](../Intent.md)로 올린다. 구글 시트는 쓰지 않는다.

측정 환경: 단위 시험은 Node 24.20.0, 실제 확장 점검은 **Ego Lite(Chromium 156)**. 요구 환경인 실제 Chrome에서는 아직 못 했다. 화면 확인은 캔버스 픽셀과 화면 구조 읽기로 했고, 눈으로 본 확인은 사용자 QA 몫이다. Ego Lite 창이 최소화되어 있어 그리기 시간은 재지 못했다.
