# 11. 화면 디자인 정리 (2026-11-14)

기능은 그대로 두고 그래프 화면과 설정 화면의 모양을 한 규칙으로 정리했다. 사용자 인터뷰(2026-11-14)에서 정한 것:

| 질문 | 결정 |
|---|---|
| 전체 느낌 | **노션처럼**: 부드러운 회색, 옅은 테두리, 둥근 모서리, 마우스를 올리면 배경이 바뀜. 밝은·어두운 테마는 시스템 설정을 따른다. 그래프 점 색(검증한 팔레트)은 그대로 |
| 도구줄 | 함께 고르는 버튼은 붙은 버튼 묶음(세그먼트): [옆 패널\|가운데 창\|전체 화면], **[그래프\|목록\|언급 정리]**("목록으로 보기"·"언급 정리" 두 버튼을 하나로, 라디오 묶음이라 방향키로 고른다). 설정은 아이콘+글자 |
| 아이콘 | 설정·검색·확대/축소/맞춤·내보내기·열기에만 직접 그린 SVG 선 아이콘. 글자 이름은 남긴다 |
| 글꼴 | 시스템 글꼴(Windows는 맑은 고딕). 글꼴 파일은 넣지 않는다 |
| 범위 | 그래프 화면(도구줄·서랍·목록 보기·언급 정리·확대 버튼·그래프 이름표)과 설정 화면. 동작은 바꾸지 않는다 |

## 디자인 값 (`src/extension/ui.css`)
두 화면이 같은 파일을 쓴다. 값은 여기 한 곳에만 둔다.

| 이름 | 밝은 | 어두운 | 쓰임 |
|---|---|---|---|
| `--bg` | #ffffff | #191919 | 바탕(그래프 팔레트 `background`와 같음) |
| `--surface` | #f7f7f5 | #202020 | 서랍·설정 바탕·세그먼트 바탕 |
| `--hover` / `--pressed` | #efefed / #e5e5e2 | #2c2c2c / #373737 | 마우스 올림·누름 |
| `--text` | #37352f | #e6e6e3 | 글자(그래프 팔레트 `text`와 같음) |
| `--muted` | #6b6a65 | #9b9b98 | 보조 글자 |
| `--border` / `--border-strong` | #e3e2df / #8c8b87 | #2f2f2f / #6b6b6b | 꾸밈 테두리 / 입력칸 테두리 |
| `--accent` / `--on-accent` | #1a6fc4 / #ffffff | #5aa2e8 / #191919 | 주요 버튼(설정 열기·Notion에서 열기·확인하고 저장·연결 지도 만들기) |
| `--ring` | #2383e2 | #5aa2e8 | 키보드 초점 테두리 |
| `--danger` | #b42318 | #ff8a80 | 지우기 버튼 글자·PAT 경고 테두리 |

- 대비: 글자 4.5:1, 입력칸 테두리·초점 3:1 이상을 `tests/uiTokens.test.ts`가 계산으로 검사한다(NF-3). 꾸밈 테두리(`--border`)는 구분에 필요하지 않은 선이라 검사하지 않는다.
- 고른 상태는 색만으로 알리지 않는다: 세그먼트는 바탕·그림자·굵기, 범례 칩 숨김은 줄긋기·흐림.
- 모서리 6px, 기본 높이 28px, 글자 14px(보조 12px, 제목 16px).

## 바뀐 것
- 그래프 화면: 위 도구줄 구성, 범례 칩, "보기·내보내기" 펼침 판(그림자·제목), 상태 줄 작은 회색 글씨, 알림 상자, 확대 버튼 묶음 카드, 빈 화면 버튼, 목록 표 머리 고정, 언급 정리 카드, 서랍(회색 바탕, 목록 줄 마우스 올림).
- 그래프 이름표: 글자 둘레를 바탕색으로 한 번 그려 선·다른 이름표와 겹쳐도 읽힌다.
- 설정 화면: 단계마다 카드, 준비 상황 단계 표시(동그라미 + 글자), 주요·위험 버튼 구분.
- "그래프로 보기" 문구는 세그먼트 "그래프"로 바뀌어, 목록에서 그림 저장 안내도 "\"그래프\" 보기에서"로 고쳤다. 언급 정리를 보는 동안도 그림 저장은 안내만 한다.

## 확인하지 못한 것
- 실제 Chrome 옆 패널·가운데 창(노션 위)에서 어울리는지는 눈으로 보지 않았다(사용자 확인).
- macOS 글꼴에서의 모양.
