# 시험(Spike) 안내 — 사용자가 직접 하는 일

목적: 문서만으로는 확인하지 못한 것(S-1~S-7)을 실제 Chrome과 내 Notion으로 확인한다. 시험은 **읽기 요청만** 보내서 Notion 내용을 바꾸지 않는다(S-4에서 내가 직접 고치는 것만 예외).

> **토큰은 시험 패널의 입력칸에만 붙여 넣는다. 채팅·메모·문서에는 쓰지 않는다.** 결과 상자에는 토큰과 페이지 제목이 나오지 않게 만들었다. 그래도 알려 주기 전에 한 번 훑어본다.

## 1. 확장 올리기
1. Chrome 주소창에 `chrome://extensions`를 입력한다.
2. 오른쪽 위 **개발자 모드**를 켠다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 `C:\Notidian\dist` 폴더를 고른다.
4. Notidian 카드에 빨간 **오류** 버튼이 보이면 눌러서 내용을 알려 준다.
5. 툴바의 퍼즐 조각 아이콘에서 Notidian을 **고정**한다.

## 2. Notion에서 내부 연결(통합) 만들기
1. 공식 안내를 따른다: <https://developers.notion.com/guides/connections-and-tokens/internal-connections> (메뉴 이름이 바뀌었을 수 있어서 정확한 클릭 경로는 확인하지 못했다. 문서 순서대로 한다.)
2. 권한(Capabilities)은 **콘텐츠 읽기만** 켜고 수정·삽입·사용자 정보는 끈다.
   - ▶ 알려 줄 것(**S-2**): 읽기만 켜는 것이 **가능했는지 / 불가능했는지 / 화면에 없었는지**
3. Notion에서 **상위 페이지 하나만** 이 연결에 추가한다(페이지 오른쪽 위 `⋯` → 연결 → 방금 만든 연결). 하위 페이지가 따라오는지 보려는 것이라 하나만 한다.
4. 연결의 토큰(Internal Integration Secret)을 복사한다.

## 3. 시험 패널 열기와 토큰 넣기
1. `chrome://extensions`에서 Notidian 카드의 **세부정보** → **확장 프로그램 옵션**을 연다.
2. 토큰을 붙여 넣고 **토큰 저장**을 누른다(입력칸은 저장하면 비워진다).

## 4. 시험 순서
각 버튼을 누르고 결과 상자의 글을 본다.

| 시험 | 하는 일 | 알려 줄 것 |
|---|---|---|
| **S-1** | **S-1 연결 확인** 버튼 | 결과 줄 전체. 상태 200이면 통과, 실패 문구가 나오면 그대로 |
| **S-2** | **S-2 페이지 전체 검색** 버튼 | 결과 줄 전체 + 내가 연결한 범위에 실제로 대략 몇 페이지·데이터베이스 항목이 있는지. 하위 페이지와 데이터베이스 항목이 검색에 나왔는지 |
| **S-3·S-7** | **S-3·S-7 50페이지 읽기** 버튼. 1분 안팎 걸린다 | 결과 줄 전체 |
| **S-4 (본문 수정)** | ① **S-4 스냅샷 저장** → ② Notion에서 아무 페이지의 본문을 한 글자 고치고, 그 페이지 주소 끝 32자리 중 **앞 8자리**를 적어 둔다 → ③ 1~2분 기다린 뒤 **S-4 비교** | 비교 결과 줄 전체, 그리고 ②의 페이지가 "바뀐 페이지" 목록에 있었는지 |
| **S-4 (이름 변경)** | ① **S-4 스냅샷 저장** → ② 다른 페이지에서 @언급된 페이지 A의 **제목만** 바꾼다. A를 언급한 페이지 B의 주소 앞 8자리를 적어 둔다 → ③ 1~2분 뒤 **S-4 비교** | B가 "바뀐 페이지"에 있었는지 |
| **S-5** | 모드를 **중앙**으로 저장 → `app.notion.com` 탭에서 Notidian 아이콘 클릭 | 창이 떴는지, 안에 점·선이 움직이고 왼쪽 위에 `force-graph=OK`가 보이는지, **Esc**와 창 바깥 클릭으로 닫히는지. 안 뜨면 `F12` → Console의 빨간 글자 |
| **S-6** | 모드를 **사이드**로 저장 → Notion 탭에서 아이콘 클릭 → 사이드 패널이 열리는지. 이어서 `chrome://extensions`의 Notidian **서비스 워커**가 "비활성"이 될 때까지(약 30초~1분) 아무것도 안 하고 기다린 뒤, Notion 탭에서 아이콘을 다시 클릭 | 두 번 모두 패널이 열렸는지. 모드 **전체**도 한 번 눌러서 새 탭이 열리는지 |
| 기록 | **S-5·S-6 결과 보기** 버튼 | 결과 줄 전체 |

(S-8 2,000 점 그래프 성능은 가짜 데이터로 제가 직접 잰다.)

## 5. 알려 주는 형식
결과 상자의 글을 **그대로 복사**해서 붙여 주고, 위 표의 "알려 줄 것"을 덧붙인다. 안 된 것이 있으면 어느 단계에서 어떤 글이 보였는지만 적어도 충분하다.

## 6. 끝난 뒤
- 시험 토큰은 쓸모가 끝나면 Notion의 연결 설정에서 삭제하는 것을 권한다.
- 이 패널은 임시 시험용이고 실제 설정 화면은 M5에서 만든다.
