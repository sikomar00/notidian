# 그래프는 계정 전체이고, 연결은 네 가지, 계층은 기본으로 그리지 않는다

처음에는 현재 페이지 중심의 로컬 그래프를 먼저 만들려 했지만, "페이지라는 장벽 없이 모든 페이지를 언급하고 이어지게" 하려는 목적에 맞춰 계정 전체 그래프로 정했다. 연결은 @언급, 본문 링크, "페이지로 연결" 블록, relation 속성 네 가지다. 상하위 계층은 기본으로 켜면 모든 페이지가 하나의 거대한 나무가 되어 언급 관계가 묻히므로, 스위치로 켜고 끄게 한다.

## Consequences
- 로컬 그래프로 시작하면 필요 없었을 전체 읽기가 필수가 된다. → [ADR 0001](./0001-official-api-full-index.md)
- 페이지가 아주 많은 계정에서 그리기 성능은 확인하지 못했다.
