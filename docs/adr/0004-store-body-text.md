# 연결 안 된 언급을 찾으려고 본문 글자를 내 컴퓨터에 저장한다

연결 안 된 언급은 "다른 페이지 본문에 이 제목이 글자로 있는가"를 봐야 한다. 연결 지도를 만들 때 본문을 이미 받지만 지금은 링크만 고르고 글자는 버린다. 본문 글자를 IndexedDB에 페이지마다 저장하고, 언급 찾기는 그래프 화면을 열 때 저장된 글자와 지금의 제목 목록으로 계산한다. 본문은 브라우저 밖으로 나가지 않고, "저장된 데이터 지우기"로 함께 지워진다.

## Considered Options
- **찾은 결과만 저장:** 본문을 남기지 않아 저장하는 개인 데이터가 적다. 하지만 바뀌지 않은 옛 페이지는 다시 읽지 않으므로(F-6), 새 페이지가 생기거나 제목이 바뀌면 옛 페이지들을 전부 다시 읽기 전까지 그 제목의 언급을 못 찾는다. 앞뒤 문장도 미리 정한 길이만 보여 줄 수 있다.
- **본문 글자 저장(채택):** 새 페이지·제목 변경을 바로 반영하고 앞뒤 문장을 보여 줄 수 있다. 대신 본문이 내 컴퓨터에 남는다.

## Consequences
- 이미 만든 연결 지도에는 글자가 없어서, 업데이트 뒤 첫 다시 만들기는 전체를 다시 읽는다.
- 저장 크기가 늘어난다(500페이지에 몇 MB로 짐작, 재 보지 않았다).
- Notion으로 가는 요청 수는 늘지 않는다.
