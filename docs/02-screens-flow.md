# 2. 화면·흐름 — IA + User Journey (초안 — 승인 대기)

용어는 [GLOSSARY](../GLOSSARY.md), 문제와 목표는 [01-problem](./01-problem.md)을 본다. 이 문서의 ID(S·UJ)는 PRD와 Intent가 참조한다.

## 1. 정보 구조 (IA)

화면은 두 개다.

```
Notidian
├─ S1 설정 화면 (Chrome 확장 설정 페이지)
└─ S2 그래프 화면
    ├─ 사이드 컨테이너 (Chrome 사이드 패널)
    ├─ 중앙 컨테이너 (Notion 페이지 위에 뜨는 창)
    └─ 전체 컨테이너 (새 탭)
```
S2는 같은 그래프 화면 하나를 세 컨테이너에 담는 것이다. 컨테이너마다 화면을 따로 만들지 않는다.

### S1 설정 화면
| ID | 요소 | 동작 |
|---|---|---|
| S1-1 | 토큰 입력 + "확인" 버튼 | 붙여 넣은 토큰을 Notion에 한 번 물어 맞는지 검사하고, 틀리면 이유를 쉬운 말로 보여 준다 |
| S1-2 | "색인 시작/중단" 버튼 + 진행률 | 색인을 시작·중단한다. 중단하거나 끊겨도 다음에 이어서 읽는다 |
| S1-3 | "다시 색인" 버튼 | 수정된 페이지만 다시 읽는다 |
| S1-4 | "캐시 삭제" 버튼 | 저장한 색인을 지운다 |
| S1-5 | 읽지 못한 페이지 목록 | 권한 없음·삭제됨으로 건너뛴 페이지를 보여 준다 |
| S1-6 | "그래프 열기" 버튼 | 색인이 있을 때 S2를 연다 |

### S2 그래프 화면
| ID | 요소 | 동작 |
|---|---|---|
| S2-1 | 보기 모드 버튼 3개 | 사이드/중앙/전체로 바꾼다. 마지막에 고른 모드를 기억한다(처음은 사이드) |
| S2-2 | 제목 검색창 | 결과를 고르면 그 점으로 이동한다. 방향키·Enter로도 쓸 수 있다 |
| S2-3 | 계층 스위치 | 상하위 계층을 그릴지 정한다(기본 꺼짐) |
| S2-4 | 색인 상태 한 줄 + 설정 열기 링크 + "다시 색인" 버튼 | 예: "읽은 페이지 120개 / 발견한 페이지 340개". 설정 열기는 S1로 간다 |
| S2-4a | (2026-11-13 변경) | "설정 열기"는 맨 윗줄 보기 모드 버튼 바로 뒤로 옮겼다. 상태 줄에는 진행 문구와 "다시 만들기"만 둔다. 선택한 페이지와 받은·보낸 연결은 그래프 아래 서랍에 둔다 |
| S2-5 | 그래프 본문 | 확대·축소·끌어서 이동. 점에 마우스를 올리면 제목 표시와 그 점의 연결 강조(방향 화살표 포함). 점을 누르면 해당 Notion 페이지로 이동 |

### 점·연결의 모양
- 점 라벨은 페이지 제목이고, 확대하거나 마우스를 올리면 보인다.
- 점 크기는 연결이 많을수록 크다.
- 색은 "일반 페이지"와 "데이터베이스 항목" 두 가지이고, 색만으로 구분하지 않도록 모양도 다르다(원/네모).
- 연결은 얇은 단색 선이다. 밝은/어두운 테마는 시스템 설정을 따른다.
- 첫 버전에서 뺀 것: 페이지 아이콘(이모지), 연결 종류별 선 모양.

## 2. 보기 모드 컨테이너

| 모드 | 여는 법 | 닫는 법 | 점을 누르면 |
|---|---|---|---|
| 사이드 | 확장 아이콘 | 패널 닫기 | 지금 보던 탭에서 이동, 패널 유지 |
| 중앙 | 확장 아이콘 | 아이콘 다시 누르기, Esc | 지금 보던 탭에서 이동, 창은 닫힘 |
| 전체 | 확장 아이콘 | 탭 닫기 | 새 탭으로 열기 |

단축키는 첫 버전에서 뺀다.

## 3. User Journey

### UJ-1 첫 실행 (설치 → 첫 그래프)
1. 설치하고 확장 아이콘을 누른다. 토큰이나 색인이 없으니 S1이 열린다.
2. 토큰 만드는 법 안내를 읽는다. *(안내 문구는 토큰 시험 후 확정)*
3. 토큰을 붙여 넣고 "확인"(S1-1)을 누른다. 맞으면 통과, 틀리면 이유가 나온다.
4. "색인 시작"(S1-2)을 누르고 진행률을 본다. 몇 분 걸릴 수 있다(추정).
5. 끝나면 "그래프 열기"(S1-6)를 눌러 S2를 본다.

### UJ-2 그래프로 탐색하기
1. Notion 페이지를 보다가 확장 아이콘을 누른다. 마지막에 쓴 모드로 S2가 열리고, 지금 보던 페이지의 점이 강조되어 가운데 온다.
2. 점에 마우스를 올려 그 점의 연결을 본다. 검색창으로 다른 페이지를 찾아 이동한다.
3. 점을 눌러 해당 Notion 페이지로 간다.

### UJ-3 최신화
1. Notion에서 페이지를 고치거나 연결을 추가했다.
2. S2 상단 또는 S1에서 "다시 색인"(S2-4 / S1-3)을 누른다. 수정된 페이지만 다시 읽는다.
3. 그래프에 새 연결이 나타난다. 자동 갱신은 하지 않는다.

### UJ-4 색인 중에 그래프 열기
1. 색인이 진행 중일 때 아이콘을 누른다.
2. 지금까지 읽은 만큼의 그래프가 보이고, 상단에 "읽은 페이지 n개 / 발견한 페이지 m개"가 나온다(S2-4).
3. 색인이 계속되는 동안 그래프를 다시 열면 더 많이 보인다.

### UJ-5 보기 모드 바꾸기
1. S2-1의 세 버튼 중 하나를 누른다.
2. 같은 그래프가 다른 컨테이너에 뜨고, 다음에 아이콘을 누르면 그 모드로 열린다.

## 4. 오류·예외 흐름

| 상황 | 동작 |
|---|---|
| 토큰이 틀리거나 만료됨(401) | S1로 안내하고 이유를 쉬운 말로 알려 준다 |
| 호출 제한(429) | 자동으로 기다렸다가 다시 시도한다. 진행률에 "잠시 대기 중"을 표시한다 |
| 읽을 수 없는 페이지(권한 없음·삭제됨) | 건너뛰고 개수만 보여 준다. 목록은 S1-5에서 본다 |
| 브라우저가 꺼지거나 색인이 끊김 | 다음 색인 시작 때 이어서 읽는다 |
| 색인이 아직 없음 | 아이콘을 누르면 S2 대신 S1을 연다 |

## 5. 초안 기본값 — 인터뷰에서 따로 묻지 않은 것
승인하시면 확정된다. 바꾸고 싶으면 알려 주세요.
- 중앙 창은 화면의 약 80% 크기로 띄우고, 바깥을 누르거나 Esc를 누르면 닫는다.
- 사이드 패널의 폭은 Chrome이 정하며 확장이 바꿀 수 없다고 알고 있다(미확인).
- 전체 모드는 이미 열린 Notidian 탭이 있으면 새로 열지 않고 그 탭을 앞으로 가져온다.
- 색인이 끝나도 별도 알림(토스트·배지)은 두지 않는다. S1과 S2-4의 상태 한 줄이 "완료"로 바뀌는 것으로 충분하다고 본다.

## 6. 접근성 기본
- 검색창과 그래프 상단 버튼은 키보드로 모두 쓸 수 있다.
- 색만으로 구분하지 않는다(점 모양을 함께 쓴다).
- 글자와 선의 색 대비를 확보한다. 구체 기준은 PRD(NF)에서 정한다.
- 그래프 본문(캔버스)은 마우스 중심이라 키보드로 점을 고를 수단이 검색창이다. 이 한계는 의도한 것이다.

## 7. 이 문서에서 정하지 않은 것
- 숫자 기준(열리는 시간, 색인 허용 시간 등) → PRD
- 저장하는 데이터의 모양 → Spec의 "저장 데이터" 절
- 사이드 패널을 아이콘 클릭으로 여는 조건, 중앙 창과 Notion 스타일의 충돌 여부 → Spec에서 시험으로 확인
