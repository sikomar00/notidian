# 14. 선 위에서 근거 보기 (승인 2026-11-14)

다음 기능 순서(사용자 결정 2026-11-14): **선 위에서 근거 보기 → 그래프 색 그룹 → 무작위·잊힌 페이지**. 이 문서는 첫 번째다. 작은 기능이라 문제·화면·요구·설계를 한 문서에 두고, 따로 묻지 않은 것은 기본값으로 적는다.

## 문제
연결 근거([13](./13-link-evidence-path.md))는 고른 페이지의 패널에서만 보인다. 그래프를 훑다가 "이 선은 왜 있지?"가 궁금하면 한쪽 끝 페이지를 골라 목록에서 찾아야 한다.

## 동작 (기본값)
- 그래프 **선에 마우스를 올리면** 커서 옆에 작은 말풍선: `A → B` 와 근거 한 줄(패널과 같은 모양). 양쪽으로 이어진 선은 두 방향을 모두, 하위 페이지 선은 `A의 하위 페이지 B`.
- 근거를 모으기 전 연결이면 근거 줄 대신 "연결"만.
- 올린 선은 굵게 강조(점에 올릴 때와 같은 색). 점과 선이 겹치면 **점이 먼저**다.
- 선 판정 거리: 화면에서 5px 안. 마우스가 그래프 밖으로 나가면 사라진다.
- 마우스 전용이다. 키보드·화면 읽기 프로그램은 같은 내용을 패널의 받은·보낸 연결에서 본다(말풍선은 `aria-hidden`).

## 요구
| ID | 요구 | 수용 기준 | 확인 |
|---|---|---|---|
| F-33 | 선 근거 말풍선 | 선에 올리면 방향·근거, 양방향은 둘 다, 하위 페이지 선은 하위 관계. 점이 먼저 | C(단위·화면 점검) |
| F-34 | 강조·사라짐 | 올린 선 굵게, 그래프 밖·점 위·빈 곳에서는 말풍선 없음, 그래프 영역 밖으로 넘치지 않음 | C |
| NF-16 | 속도 | 2,000점·선 5,000개에서 마우스 움직임마다 선 찾기가 화면을 멈추지 않는다(한 프레임에 한 번만 계산) | C |

## 설계
- `hitTest.ts`(새, 순수): 점과 선분 사이 거리, 가장 가까운 선 찾기. 단위 시험.
- `render.ts`: 지금의 직접 호버 판정(`setupHover`)에 선 판정을 더한다. 점이 없을 때만 선을 찾고, 찾은 선을 `isActive`로 강조한다. 바뀔 때 `onLinkHover(link, 화면 좌표)`를 부른다. 마우스 움직임은 `requestAnimationFrame`으로 한 프레임에 한 번만 처리한다.
- `linkTooltip.ts`(새): 말풍선 내용(순수 함수 `tooltipRows`로 방향·근거 계산, 시험)과 위치(그래프 영역 안으로 맞춤). 근거 한 줄은 `evidenceLine` 재사용.
- 자동 화면 점검: 예시 데이터에서 그래프 위를 격자로 훑어 말풍선이 나오는 곳을 찾고, 내용과 사라짐을 확인한다.
