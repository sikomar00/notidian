## 7차 리뷰: P2-1 로컬 그래프 (2026-11-13)
코드 리뷰 10건 모두 수정. 강조·화면 이동 규칙을 하나로 정리했다: **화면 이동**은 주변만 볼 때 전체 맞춤, 아니면 지금 페이지로 처음 한 번만 옮기고 그 뒤로는 자동 맞춤을 따른다. **강조**는 선택한 페이지, 없으면 지금 페이지이며, 강조만 바꿀 때는 기다리는 맞춤·이동을 취소하지 않는다. 수정 뒤 단위 시험 84개, Chrome 로컬 그래프 5/5·그래프 회귀·따라가기 7/7·좁은 화면 점검 통과.
