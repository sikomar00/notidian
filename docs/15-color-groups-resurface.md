# 15. 그래프 색 그룹과 다시 볼 페이지 (승인 2026-11-14)

다음 기능 순서(사용자 결정): 선 위 근거 보기([14](./14-link-hover.md)) → **그래프 색 그룹** → **다시 볼 페이지**. 두 기능 모두 지금 데이터로 만들고 Notion 요청을 늘리지 않는다.

## A. 그래프 색 그룹 (옵시디언 "Groups")
### 정한 것 (인터뷰 2026-11-14)
| 질문 | 결정 |
|---|---|
| 조건 | 제목에 든 글자 · DB · 상위 페이지 아래(하위의 하위까지). 노션 태그는 속성 저장이 필요해 뺀다 |
| 개수·겹침 | 최대 6개. 여러 그룹에 걸리면 목록에서 위의 그룹 색. ↑↓로 순서를 바꾼다. 색은 미리 정한 6가지(보라·분홍·초록·청록·빨강·연두)에서 고른다 |
| DB별 색과 | 그룹 색이 먼저. 어느 그룹에도 안 걸린 점은 종류·DB별 색 그대로 |
| 화면 | "보기·내보내기" 안 "색 그룹" 칸(줄마다 색·조건·값·↑·↓·×, 아래 "+ 그룹 추가"). 범례 줄 아래 "● 이름 N개". 고른 페이지 패널에 "그룹: 이름". 이 브라우저에 기억(예시 모드는 저장 안 함) |

### 요구
| ID | 요구 | 수용 기준 | 확인 |
|---|---|---|---|
| F-35 | 그룹 만들기 | 세 조건으로 그룹을 만들면 맞는 점이 그 색, 범례에 개수. 상위 페이지는 하위의 하위까지(중간 페이지가 숨겨져도) | C |
| F-36 | 순서·겹침·지우기 | 위의 그룹이 먼저, ↑↓·×가 키보드로 되고 바꾼 뒤 초점이 옮겨 간 그룹을 따라간다 | C |
| F-37 | 색만으로 구분하지 않기 | 범례 글자와 패널 "그룹:" 줄 | C |
| NF-17 | 저장·속도 | 저장은 `colorGroups`만, 저장된 데이터 지우기로 함께 지움. 그룹이 없으면 계산하지 않고, 데이터가 바뀔 때만 계산. 지도를 만드는 중에도 편집 중인 칸을 다시 그리지 않는다 | C |

### 한계(`shortcut:`)
그룹 여섯 색끼리·DB 색과의 색각 이상 구분은 검사하지 않았다. 범례 글자와 패널 글자로 보완한다.

## B. 다시 볼 페이지 (옵시디언 "무작위 노트")
### 정한 것
| 질문 | 결정 |
|---|---|
| 무엇을 | 잊힌 페이지(수정 시각 오래된 20%)·무작위·외톨이(연결 1개 이하). 처음 값은 잊힌 페이지 |
| 보여 주기 | 그래프에서 고른 것처럼(가운데로, 패널 열기). 패널에 "마지막 수정: N 전" |
| 버튼 자리 | 도구줄 "보기·내보내기 · 주변만" 줄 끝의 [다른 페이지](좁으면 아이콘만). 종류는 "보기·내보내기" 메뉴 안. 처음 계획한 상태 줄은 좁은 화면에서 한 줄이 늘어(217px) 옮겼다 |
| 반복 | 화면을 연 동안 이미 꺼낸 페이지는 다시 안 꺼내고, 다 돌면 처음부터. 저장하지 않는다 |

### 요구
| ID | 요구 | 수용 기준 | 확인 |
|---|---|---|---|
| F-38 | 꺼내기 | 종류에 맞는 페이지를 골라 패널을 연다. 키보드로 거듭 누를 수 있게 초점은 버튼에 두고 꺼낸 페이지를 알린다 | C |
| F-39 | 반복 피하기 | 다 돌기 전에는 같은 페이지가 다시 안 나온다 | C |
