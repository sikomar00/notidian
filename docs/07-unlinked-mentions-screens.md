# 7. 연결 안 된 언급 — 화면·흐름 (승인 2026-11-14)

용어는 [GLOSSARY](../GLOSSARY.md), 문제와 목표는 [06 문제 정의](./06-unlinked-mentions-problem.md)를 본다. 첫 기능의 화면 ID(S1·S2·UJ-1~5)는 [02 문서](./02-screens-flow.md)를 그대로 쓰고, 여기서는 새로 생기는 것만 적는다. 새 화면은 없다.

## 1. 정보 구조 (IA) — 바뀌는 곳

```
S2 그래프 화면
└─ 선택한 페이지 서랍 (그래프 아래)
    ├─ 받은 연결          (있음, P2-2)
    ├─ 보낸 연결          (있음, P2-2)
    └─ S2-7 연결 안 된 언급   ← 새로
S1 설정 화면
└─ S1-4 저장된 데이터 지우기   ← 지우는 대상에 본문 글자가 더해짐(버튼은 그대로)
```

### S2-7 연결 안 된 언급 칸
| ID | 요소 | 동작 |
|---|---|---|
| S2-7a | 제목 "연결 안 된 언급 N개" + 한 줄 설명 | 설명: "이 페이지 제목을 연결 없이 글자로만 적은 페이지". N은 찾은 페이지 수 |
| S2-7b | 결과 목록 | 한 줄에 페이지 제목, 앞뒤 약 30자(찾은 글자는 굵게), 나온 횟수("3곳"). 나온 횟수가 많은 순 |
| S2-7c | 결과 누르기 | 그 페이지를 Notion에서 연다(보기 모드별 열기 규칙은 02 문서 2절과 같다). 거기서 내가 직접 @언급을 건다 |
| S2-7d | 상태 안내 | 결과 대신 한 줄 안내를 보여 준다(아래 3절) |

배치: 받은·보낸 연결 옆의 세 번째 칸이다. 옆 패널처럼 좁으면 아래로 쌓인다(지금 서랍과 같은 방식).

## 2. User Journey

### UJ-6 글자로만 적은 곳을 찾아 연결 걸기
1. Notion에서 "회의록" 페이지를 보다가 아이콘을 누른다. 그래프가 열리고 이 페이지가 선택된다(지금과 같다).
2. 서랍의 "연결 안 된 언급 4개"를 본다. 각 줄의 앞뒤 문장으로 정말 이 페이지 얘기인지 판단한다.
3. 링크 걸 만한 줄을 누른다. 그 페이지가 Notion에서 열린다.
4. Notion에서 그 글자를 @언급으로 바꾼다.
5. 다음 "다시 만들기" 뒤에는 그 줄이 "연결 안 된 언급"에서 빠지고 "받은 연결"로 옮겨 간다.

### UJ-7 업데이트 뒤 처음 쓰기
1. 확장을 업데이트하고 그래프를 연다. 서랍의 칸에 "다시 만들기를 하면 보여요"가 나온다.
2. "다시 만들기"를 누른다. 상태 줄에 "본문을 처음 모으느라 이번엔 전체를 다시 읽어요"가 함께 나온다.
3. 끝나면 칸에 결과가 나온다. 그 뒤로는 바뀐 페이지만 읽는다(지금과 같다).

## 3. 상태·예외 흐름

| 상황 | S2-7에 보이는 것 |
|---|---|
| 아직 본문을 모은 적 없음 | "다시 만들기를 하면 보여요" |
| 본문을 모으는 중(다시 만들기 진행 중) | 지금까지 모은 만큼으로 찾은 결과 + "연결 지도를 만드는 중이라 더 나올 수 있어요" |
| 찾은 것이 없음 | "글자로만 적은 곳이 없어요" |
| 제목이 2글자 이하이거나 "제목 없음" | "제목이 너무 짧아서 찾지 않아요" |
| 읽을 수 없는 페이지(회색 점)를 고름 | 칸을 숨긴다(제목을 모른다) |
| 예시로 둘러보기(P2-7) | 예시 데이터의 가짜 본문으로 결과를 보여 준다 |

## 4. 초안 기본값 — 인터뷰에서 따로 묻지 않은 것
승인하시면 확정된다. 바꾸고 싶으면 알려 주세요.
- **결과를 누르면 Notion에서 연다.** 받은·보낸 연결은 누르면 그래프에서 그 페이지를 고르는데, 여기는 목적이 "가서 연결 걸기"라서 다르게 한다.
- 결과는 처음 50개만 보여 주고, 더 있으면 "N개 더 있어요"라고만 적는다(흔한 제목 대비).
- 앞뒤 문장은 첫 번째로 나온 곳 하나만 보여 준다.
- 목록 보기(표)와 CSV 내보내기에는 이번에 넣지 않는다.
- 그래프 점 모양·색은 바꾸지 않는다.

## 5. 접근성
- 결과 줄은 버튼이라 Tab·Enter로 쓸 수 있다. 굵게 표시는 색이 아니라 글자 굵기로 한다.
- 화면 읽기 프로그램에는 "연결 안 된 언급 N개" 제목과 각 줄의 제목·횟수를 읽힌다. 앞뒤 문장은 줄 안의 글자로 함께 읽힌다.
