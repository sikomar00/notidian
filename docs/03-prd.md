# 3. PRD (초안 — 승인 대기)

문제와 목표는 [01-problem](./01-problem.md), 화면 ID(S·UJ)는 [02-screens-flow](./02-screens-flow.md), 용어는 [GLOSSARY](../GLOSSARY.md)를 본다. 이 문서의 ID(F·NF)는 Spec, QA, Intent가 참조한다.

## 1. 범위
- 포함(첫 버전 필수): 아래 F-1~F-15, NF-1~NF-7 전부.
- 제외: 웹스토어 공개, 여러 사람이 함께 쓰기, 여러 워크스페이스, 그래프 말고 다른 옵시디언 기능, Notion 내용 수정, 자동 갱신, 단축키, 페이지 아이콘·연결 종류별 선 모양.

## 2. 규모 가정
- 페이지 500개 기준으로 설계하고, 2,000개까지는 느려져도 끝까지 동작하는 것을 목표로 한다.
- 실제 개수는 첫 색인이 끝나면 알 수 있다. 크게 다르면 NF-1을 다시 정한다.

## 3. 기능 요구 (F)
확인: **C** = Claude QA(함수 시험·가짜 데이터 점검 페이지), **H** = 사람 QA(내 실제 Notion 데이터·실제 Chrome).

| ID | 요구 | 수용 기준 | 화면 | 확인 |
|---|---|---|---|---|
| F-1 | 토큰 입력과 검사 | 내부 통합 토큰(우선)이나 PAT 중 맞는 토큰을 넣고 "확인"하면 통과 표시가 나온다. 틀리거나 만료된 토큰은 이유를 쉬운 말로 보여 준다. 토큰은 `chrome.storage.local`에만 저장된다. | S1-1 / UJ-1 | C(오류 문구), H(실제 토큰) |
| F-2 | 전체 색인 | 접근 가능한 모든 페이지와 데이터베이스 항목을 읽어 색인을 만든다. 진행률("읽은 n개 / 발견한 m개")이 보이고, 중단할 수 있다. | S1-2 / UJ-1 | C(함수), H(실제 데이터) |
| F-3 | 연결 추출 | 연결 네 종류(@언급, 본문 속 Notion 링크, "페이지로 연결" 블록, relation 속성)를 모두 찾는다. 블록 안에 중첩된 것까지 찾는다. | - | C(함수, 종류별 가짜 데이터), H(NF-2) |
| F-4 | 연결 합치기 | A→B는 몇 번·어떤 종류로 가리켜도 선 하나다. A→B와 B→A는 양쪽 화살표 한 선이다. 자기 자신을 가리키는 연결은 무시한다. 휴지통·보관된 페이지는 제외한다. | - | C |
| F-5 | 읽을 수 없는 페이지 | 권한 없음·삭제된 페이지를 가리키는 연결은 점을 회색으로 그리고 "읽을 수 없는 페이지"로 표시한다. 읽지 못한 페이지의 개수와 목록을 보여 준다. 점을 누르면 이동은 그대로 시도한다. 데이터베이스를 가리키는 연결은 페이지가 아니므로 점을 만들지 않고 그래프에서 뺀다(시험 S-7). | S1-5 / 오류 흐름 | C, H |
| F-6 | 다시 색인 | 수정된 페이지만 다시 읽는다. 끝나면 새 연결이 나타나고, 지우거나 고친 연결은 사라진다. 자동 갱신은 하지 않는다. 수정 시각이 분 단위로 내림되므로 수정 시각에서 2분 이내에 읽은 페이지는 다음 색인에서 한 번 더 읽는다. 검색 색인이 수십 초 늦게 반영될 수 있어서 방금 고친 내용은 잠시 뒤에 보일 수 있다고 안내한다(시험 S-2·S-4). | S1-3, S2-4 / UJ-3 | C(변경분 판정), H |
| F-7 | 캐시 삭제 | 버튼을 누르면 저장한 색인이 모두 지워지고, 다시 아이콘을 누르면 설정 화면이 열린다. | S1-4 | C |
| F-8 | 오류 처리 | 401은 설정으로 안내한다. 429는 자동으로 기다렸다 재시도하며 "잠시 대기 중"을 표시한다. 한 페이지가 실패해도 전체 색인이 멈추지 않는다. | 오류 흐름 | C(가짜 응답으로 401·429·실패 재현) |
| F-9 | 그래프 그리기 | 점은 페이지 제목을 라벨로 갖고 연결이 많을수록 크다. 일반 페이지와 데이터베이스 항목은 색과 모양(원/네모)이 다르다. 확대·축소·끌어서 이동이 된다. 점에 마우스를 올리면 그 점의 연결이 강조되고 방향 화살표가 보인다. 점을 누르면 해당 Notion 페이지로 이동한다. | S2-5 / UJ-2 | C(점검 페이지), H(체감) |
| F-10 | 현재 페이지 강조 | 그래프를 열면 지금 보던 Notion 페이지의 점이 강조되고 가운데 온다. 그 페이지가 색인에 없으면 강조 없이 연다. | UJ-2 | C, H |
| F-11 | 제목 검색 | 제목으로 검색해 결과를 고르면 그 점으로 이동한다. 방향키와 Enter로 쓸 수 있다. | S2-2 | C |
| F-12 | 계층 스위치 | 켜면 상하위 계층이 선으로 추가되고, 끄면(기본) 사라진다. | S2-3 | C |
| F-13 | 보기 모드 | 사이드/중앙/전체를 버튼으로 바꾸고 마지막에 고른 모드를 기억한다(처음은 사이드). 각 모드의 열기·닫기·점 클릭 동작은 [02 문서 2절](./02-screens-flow.md)과 같다. | S2-1 / UJ-5 | C(상태 기억), H(실제 창) |
| F-14 | 아이콘 진입 | 아이콘을 누르면 마지막에 쓴 모드로 그래프를 연다. 색인이나 토큰이 없으면 설정 화면을 연다. | UJ-1, UJ-2 | C, H |
| F-15 | 색인 중 그래프 열기 | 색인 중에도 그래프를 열 수 있다. 지금까지 읽은 만큼 보이고 상단에 읽은 개수와 발견한 개수가 표시된다. | S2-4 / UJ-4 | C, H |

## 4. 비기능 요구 (NF)

| ID | 요구 | 수용 기준 | 확인 |
|---|---|---|---|
| NF-1 | 성능(500페이지 기준) | 처음 전체 색인 **10분 이내**. 변경 없을 때 "다시 색인" **30초 이내**. 색인이 끝난 뒤 아이콘을 누르고 그래프가 보일 때까지 **3초 이내**. 2,000페이지에서는 그래프 열림 **10초 이내**를 목표로 한다. 숫자는 추정이라 토큰·CORS 시험 뒤 실측으로 고친다. | 그래프 열림은 C(가짜 500·2,000 점 데이터), 색인 시간은 H(실제 토큰) |
| NF-2 | 연결 정확도 | 내가 고른 연결 20개(네 종류 각 5개)가 그래프에 **모두** 나온다. 없는 연결이 그려지지 않는다. 지우거나 고친 연결은 "다시 색인" 뒤에 사라진다. | H |
| NF-3 | 접근성 | 글자 대비 4.5:1, 점·선 대비 3:1(WCAG 2.1 AA). 검색창과 모든 버튼은 키보드만으로 쓸 수 있다. 색만으로 구분하지 않는다. 그래프 본문(캔버스)은 마우스 중심이고 키보드로 점을 고르는 수단은 검색창이다(의도한 한계). | C(대비 계산), H(키보드) |
| NF-4 | 개인정보 | 개발자 도구 네트워크 탭에서 요청 목적지가 `api.notion.com`·`app.notion.com` 외에 없다. 저장은 `chrome.storage.local`과 IndexedDB뿐이다. 토큰이 콘솔 로그와 오류 메시지에 나오지 않는다. 확장 권한(host_permissions)은 그 두 곳뿐이다. | C(코드·매니페스트 점검, 로그 검사), H(네트워크 탭) |
| NF-5 | 읽기 전용 | 페이지 내용을 바꾸는 요청을 보내지 않는다. 코드의 요청 함수는 읽기(GET)와 검색(`POST /v1/search`)만 허용하고 그 밖은 막는다. 내부 통합 토큰은 읽기 권한만 켠다. PAT는 읽기 전용이 불가능하므로 쓰게 되면 설정 화면에 경고를 보여 준다. | C(요청 종류 점검), H(통합 토큰 설정 화면에서 읽기만 켜졌는지) |
| NF-6 | 지원 환경 | Windows의 Chrome 최신 안정판과 Notion 웹앱(`app.notion.com`)만 지원한다. Notion 데스크톱 앱, 모바일, 다른 브라우저는 시험하지 않는다. Notion 데스크톱 앱은 Chrome 확장을 올릴 수 없는 것으로 알고 있다(확인하지 못했다). | H |
| NF-7 | 이어 읽기 일관성 | 색인을 중간에 끊고 이어서 읽은 결과가 처음부터 한 번에 읽은 결과와 같다. | C |

## 5. 확인하지 못한 것 (Plan의 첫 시험 항목)
- 서비스 워커에서 `api.notion.com`을 부를 때 CORS: Ego Lite에서는 통과(2026-11-13), **실제 Chrome 확인 필요** (F-2, NF-1에 영향)
- 내부 통합 토큰: 상위 페이지 하나만 연결해도 하위 페이지·데이터베이스 항목이 모두 검색되는 것은 확인했다(2026-11-13). 읽기 전용 설정은 사용자 보고로만 확인했고 쓰기 거부는 시험하지 못했다 (F-1, F-2, NF-5에 영향)
- 전체 읽기 시간 — 500페이지 6~8분은 추정이다 (NF-1)
- 검색이 모든 페이지를 주지 않는 정도, 언급 따라가기로 충분히 보충되는지 (F-2, NF-2)
- 2,000페이지에서 그래프 그리기 성능 (NF-1)
- Notion 이용약관 원문
- Notion 데스크톱 앱의 확장 지원 여부 (NF-6)
