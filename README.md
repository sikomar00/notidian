# Notidian

노션 페이지들이 서로 어떻게 이어져 있는지 **연결 그래프**로 보여 주는 Chrome 확장이에요. 옵시디언의 그래프·백링크를 노션에서 쓰고 싶어서 만들었어요.

> 아직 개인용 단계예요. 크롬 웹스토어에는 올리지 않았고, 압축을 푼 확장으로 직접 올려 써요.

## 할 수 있는 것

- **연결 그래프:** 노션 계정 안의 페이지와 DB 항목을 점으로, @언급·본문 링크·"페이지로 연결" 블록·relation을 선으로 그려요.
- **세 가지 보기:** 옆 패널 / 가운데 창 / 전체 화면. 옆 패널은 노션에서 보는 페이지를 따라가요.
- **받은·보낸 연결(백링크):** 고른 페이지를 가리키는 페이지와, 그 페이지가 가리키는 페이지 목록.
- **연결 안 된 언급:** 고른 페이지의 제목이 다른 페이지 본문에 연결 없이 글자로만 적힌 곳을 앞뒤 문장과 함께 보여 줘요. 누르면 그 페이지가 열려서 직접 @언급을 걸 수 있어요. 업데이트 뒤 처음 "다시 만들기"는 본문을 모으느라 전체를 다시 읽어요.
- **주변만 보기:** 고른 페이지에서 1~3단계 안의 페이지만.
- **보기 옵션:** 범례를 눌러 점 종류 숨기기. 범례 줄의 "보기·내보내기"를 펼치면 연결 없는 페이지 숨기기, 하위 페이지 선, DB별 색.
- **예시로 둘러보기:** 토큰을 넣기 전에도 가짜 예시 데이터로 그래프를 써 볼 수 있어요(저장하지 않아요).
- **목록 보기와 키보드 사용:** 그래프를 표로도 볼 수 있고, 제목 검색·Enter로 열 수 있어요.
- **내보내기:** 지금 보이는 그래프를 그림(PNG)으로, 페이지·연결 목록을 CSV(엑셀에서 열림)로 저장해요. CSV는 범례·보기 설정만 반영한 전체예요(주변만 보기·검색은 빼요).
- **자동 다시 만들기(선택):** 30분·1시간·하루마다 바뀐 페이지만 다시 읽어요.

## 데이터와 개인정보

- 노션 **공식 API**로 읽기 요청만 보내요(읽기와 검색). 노션 내용을 바꾸지 않아요.
- 읽어 온 것은 **이 브라우저 안에만** 저장해요(페이지 제목·주소·연결·DB 이름, 그리고 "연결 안 된 언급"을 찾는 데 쓰는 본문 글자). 설정의 "저장된 데이터 지우기"로 모두 지워져요.
- 접속하는 곳은 `api.notion.com`과 `app.notion.com`뿐이에요. 다른 서버로 보내거나 통계를 모으지 않아요.
- 토큰은 설정 화면에서 직접 넣고, "토큰 지우기"로 지우거나 "브라우저를 닫으면 토큰 지우기"로 디스크에 남기지 않을 수 있어요.

## 설치

필요한 것: Node.js 24 이상, Chrome 116 이상(Edge·Whale에서도 자동 화면 점검을 통과했어요. 옆 패널은 브라우저마다 다를 수 있어요)

```bash
npm install
npm run build
```

1. Chrome에서 `chrome://extensions`를 열고 **개발자 모드**를 켜요.
2. **압축해제된 확장 프로그램을 로드**를 눌러 `dist` 폴더를 골라요.
3. 설정 화면이 열리면 안내대로 노션 **내부 연결(통합)** 을 만들고 권한은 **콘텐츠 읽기**만 켜요. 읽을 상위 페이지에 그 연결을 추가하고, 토큰을 붙여 넣어요.
4. "연결 지도 만들기"를 누른 뒤, 노션 페이지에서 확장 아이콘을 누르면 그래프가 열려요.

## 개발

| 명령 | 하는 일 |
|---|---|
| `npm run typecheck` | 타입 검사 |
| `npm test` | 단위 시험(Node 내장 시험 도구) |
| `npm run build` | `dist`에 확장 빌드 |
| `npm run qa:e2e` | 헤드리스 Chrome으로 화면 동작 자동 점검(가짜 데이터, 실제 노션에 접속하지 않음) |
| `npm run qa` | 그래프 그리기 속도 측정 페이지(`qa/perf.html`) |

설계와 결정 기록은 [`docs/`](docs)에 있어요(문제 정의·화면 흐름·PRD·Spec·ADR·QA·리뷰).
